수조 스캔 — 한 센서로 두 위치

연결 확인 중 노드 높이 상한 mm ← 실시간 모니터
순서
  1. 수조를 비운 채 센서를 위치 A에 두고 → A 바닥 기록
  2. 센서를 위치 B로 옮기고 (수조는 계속 빈 상태) → B 바닥 기록
  3. 수조에 물체를 넣습니다
  4. 센서를 위치 B에 둔 채 → B 현재 기록
  5. 센서를 위치 A로 옮기고 → A 현재 기록
각 위치의 바닥과 현재를 짝지어 높이를 계산합니다. 옮기는 동안 기록은 그대로 보존되니 버튼을 누를 때만 갱신됩니다.
